## 🏆 Capstone Project

### Interactive Product Inventory & Analytics Dashboard

A console-based program that manages product data and shows a full report.

*Features*

- ✅ Takes a new product name and price from the user
- ✅ Validates the input and asks again if it is wrong
- ✅ Assigns a category: *Budget, **Standard* or *Premium*
- ✅ Calculates the total inventory value
- ✅ Filters affordable items (under $200)
- ✅ Creates a formatted report with tax and discount support

## ⚙️ How to Run

*1. Download the project*

Click the green *Code* button, then *Download ZIP*. Unzip the folder.

*2. Open the runner page*

Double click run.html (it opens in your browser).

*3. Run an assignment*

Click any button, such as *Assignment 1* or *Capstone Project*. The output appears in the black box.

*4. Enter values when asked*

| Program | Sample input |
|---|---|
| Assignment 2 | Bill 100, Tip 15 |
| Assignment 3 | Score 85 |
| Capstone | Name Monitor, Price 150 |

> 💡 Press F12 and open the *Console* tab to see the same output there.
